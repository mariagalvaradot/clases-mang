Trampa #1

Raíces cuadradas y valores absolutos

✗
Si x₁² = x₂², ¿puedo concluir x₁ = x₂?
❌ Error clásico
x₁² = x₂² ⟹ x₁ = x₂
Esto es FALSO en general
✓ Correcto
x₁² = x₂² ⟹ |x₁| = |x₂| ⟹ x₁ = ±x₂
Hay dos posibilidades
¿Por qué? La raíz cuadrada de x² no es x, sino |x|. Porque (−3)² = 9 y (3)² = 9. Al sacar √ a ambos lados de x² = y² obtienes |x| = |y|, que da x = y o x = −y. En una demostración de inyectividad, si llegas a x₁² = x₂² debes analizar ambos casos, o añadir la hipótesis de que ambos son positivos para concluir x₁ = x₂.

Ejemplo concreto: (−5)² = (5)² = 25. Si solo dijeras x = 5 pierdes x = −5.

!
La regla correcta: √(x²) = |x|
√(x²) = |x|, no x

Esto se debe a que la función raíz cuadrada siempre da un resultado no negativo. Entonces:

Si x ≥ 0
√(x²) = x
Si x < 0
√(x²) = −x (positivo)
Consecuencia práctica: Si en una demostración de inyectividad te piden probar que f(x₁) = f(x₂) ⟹ x₁ = x₂, y llegas a x₁² = x₂², necesitas añadir que el dominio tiene x ≥ 0 (o x ≤ 0) para sacar la raíz y concluir x₁ = x₂ directamente.
Trampa #2

Errores con logaritmos

✗
ln(a + b) = ln(a) + ln(b) ?
❌ Error muy común
ln(a + b) = ln a + ln b
FALSO. No existe esta propiedad
✓ Lo que SÍ vale
ln(a · b) = ln a + ln b
Solo con multiplicación
Contraejemplo: ln(1 + 1) = ln 2 ≈ 0.693, pero ln 1 + ln 1 = 0 + 0 = 0. Son distintos.
✗
Otros errores de logaritmos
❌ Error
ln(a/b) = ln(a) / ln(b)
FALSO
✓ Correcto
ln(a/b) = ln a − ln b
Es resta, no división
❌ Error
(ln a)² = 2 ln a
FALSO. Confunde con ln(a²)
✓ Correcto
ln(a²) = 2 ln a
El exponente va al frente
❌ Error
ln(0) = 0 o ln(−5) = algo
FALSO: no existe
✓ Correcto
ln(1) = 0 y ln(e) = 1
Solo definido para x > 0

Las propiedades correctas de logaritmos

ln(xy) = ln x + ln y    (x>0, y>0)
ln(x/y) = ln x − ln y    (x>0, y>0)
ln(xⁿ) = n · ln x    (x>0)
ln(eˣ) = x    y    e^(ln x) = x
Trampa #3

Raíz de una suma

✗
√(a² + b²) = a + b ?
❌ Error clásico
√(a² + b²) = a + b
FALSO en casi todos los casos
✓ Realidad
√(a² + b²) ≠ a + b
No se puede simplificar más
Contraejemplo: √(3² + 4²) = √(9+16) = √25 = 5. Pero 3 + 4 = 7 ≠ 5.

Lo que sí vale: √(a²) = |a| y √(a·b) = √a · √b (con a,b ≥ 0)

✓
Lo que SÍ puedes hacer con raíces
✓ Válido
√(a · b) = √a · √b
a ≥ 0 y b ≥ 0
✓ Válido
√(a/b) = √a / √b
a ≥ 0 y b > 0
❌ Inválido
√(a + b) = √a + √b
❌ Inválido
√(a − b) = √a − √b
Trampa #4

Errores con potencias y exponentes

✗
Errores en álgebra de potencias
❌ Error

FALSO. Falta el término cruzado
✓ Correcto
(a + b)² = a² + 2ab + b²
❌ Error
aˣ · aʸ = a^(xy)
✓ Correcto
aˣ · aʸ = a^(x+y)
Misma base: sumas exponentes
❌ Error
aˣ · bˣ = (ab)^(2x)
✓ Correcto
aˣ · bˣ = (ab)ˣ
Distinta base, mismo exp.
❌ Error
(aˣ)ʸ = aˣ + aʸ
✓ Correcto
(aˣ)ʸ = a^(xy)
Potencia de potencia: multiplica
Trampa #5

Dominio: lo que la mayoría olvida

✗
"El denominador que se anule da el dominio"

El error es incluir el valor que anula el denominador en lugar de excluirlo.

❌ Error
f(x) = 1/(x−3)
Dom = {3}
3 se EXCLUYE, no se incluye
✓ Correcto
f(x) = 1/(x−3)
Dom = ℝ \ {3}
Todo excepto x = 3
✗
Olvidar que el radicando puede ser CERO
❌ Error
√(x − 2): Dom = (2, ∞)
Olvida que x=2 también sirve
✓ Correcto
√(x − 2): Dom = [2, ∞)
√0 = 0, está definida
Regla: Para √(expresión) necesitas expresión ≥ 0 (no estrictamente mayor). Para ln(expresión) necesitas expresión > 0 (aquí sí estrictamente).
✗
Confundir el dominio de f∘g

El dominio de (f∘g)(x) = f(g(x)) no es simplemente Dom(g).

Regla correcta: Dom(f∘g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}

Es decir: x debe ser válido para g, Y ADEMÁS el resultado g(x) debe ser válido para f.

Ejemplo: f(x) = √x (Dom: [0,∞)), g(x) = x−3 (Dom: ℝ)
(f∘g)(x) = √(x−3). Necesitas g(x) ≥ 0, es decir x−3 ≥ 0, entonces Dom = [3, ∞), no ℝ.

Trampa #6

La inversa NO es 1/f(x)

✗
f⁻¹(x) = 1/f(x) ?
❌ Error gravísimo
f⁻¹(x) = 1/f(x)
La notación "−1" no es exponente
✓ Significado real
f⁻¹ es la función INVERSA
La que "deshace" a f
Ejemplo: Si f(x) = 2x + 1, entonces f⁻¹(x) = (x−1)/2, no 1/(2x+1).
Verifica: f(f⁻¹(x)) = 2·(x−1)/2 + 1 = x−1+1 = x ✓

La reciprocal (1/f) a veces se escribe [f(x)]⁻¹, con los corchetes para distinguir.

Trampa #7

Álgebra de fracciones

✗
Cancelar términos que suman, no que multiplican
❌ Error
(x² + 5) / 5 = x²
No puedes "cancelar" el 5
✓ Correcto
(x² + 5) / 5 = x²/5 + 1
Divide cada término por 5
❌ Error
(x+3)(x−1) / (x+3) = x−1+3
✓ Correcto
(x+3)(x−1) / (x+3) = x−1
Cancelas el factor (x+3), x≠−3
Regla de oro: Solo puedes cancelar factores (cosas que multiplican), nunca sumandos o términos.
✗
Dividir entre una fracción
❌ Error
a / (b/c) = (a·b)/c
✓ Correcto
a / (b/c) = a · (c/b) = ac/b
Divides = multiplicas por recíproco
Trampa #8

Demostrar inyectividad: el método correcto

i
Estructura de la demostración de inyectividad

Para probar que f es inyectiva (1 a 1), debes mostrar que:

f(x₁) = f(x₂) ⟹ x₁ = x₂

Pasos:

  • Supón que f(x₁) = f(x₂) (hipótesis)
  • Trabaja algebraicamente hasta llegar a x₁ = x₂
  • Cada paso debe estar justificado
Ejemplo: f(x) = 3x − 5. Supón f(x₁) = f(x₂):
3x₁ − 5 = 3x₂ − 5 → 3x₁ = 3x₂ → x₁ = x₂ ✓ (es inyectiva)
Trampa: f(x) = x². Supón f(x₁) = f(x₂) → x₁² = x₂² → |x₁| = |x₂| → x₁ = ±x₂. No puedes concluir x₁ = x₂. Por eso f(x)=x² NO es inyectiva en ℝ (sí en [0,∞)).

Medio
▾

Inyectividad y demostración
EJ 15
Demuestra que f(x) = 4x − 7 es inyectiva.
Fácil
▾
1
Supón que f(x₁) = f(x₂)
2
Entonces: 4x₁ − 7 = 4x₂ − 7
3
Suma 7: 4x₁ = 4x₂
4
Divide entre 4: x₁ = x₂ ✓
Respuestaf es inyectiva. (Toda función lineal con m≠0 lo es.)
EJ 16
¿Es f(x) = x² inyectiva en ℝ? ¿Y en [0, +∞)?
Medio
▾
1
En ℝ: Supón f(x₁) = f(x₂) → x₁² = x₂² → |x₁| = |x₂| → x₁ = ±x₂. No necesariamente igual. Contraejemplo: f(3) = f(−3) = 9 pero 3 ≠ −3.
2
En [0,∞): Ahora x₁, x₂ ≥ 0. Si x₁² = x₂² → √(x₁²) = √(x₂²) → x₁ = x₂ (porque ambos son no negativos, la raíz da el valor sin ±).
RespuestaNO inyectiva en ℝ. SÍ inyectiva en [0, +∞).
EJ 17
Demuestra que f(x) = x³ + 2 es inyectiva en ℝ.
Medio
▾
1
Supón f(x₁) = f(x₂)
2
x₁³ + 2 = x₂³ + 2
3
x₁³ = x₂³
4
La función cúbica es inyectiva en ℝ (la raíz cúbica es única para cualquier real): x₁ = x₂ ✓. Nota: ³√(x₁³) = x₁ siempre, sin valor absoluto, porque la raíz cúbica respeta el signo.
Respuestaf(x) = x³ + 2 es inyectiva en ℝ.
