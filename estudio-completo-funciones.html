01
Función racional · Dificultad básica
f(x) = (x² − 1) / (x − 2)
Asíntota vertical · Asíntota oblicua · Extremos locales
1
Paso 1
Dominio
▾

El único problema es el denominador. Igualamos a cero:

x − 2 = 0 → x = 2
DominioDom(f) = ℝ \ {2} = (−∞, 2) ∪ (2, +∞)
⚠ Trampa frecuente

Algunos escriben Dom = {2}, incluyendo el valor problemático. Es al revés: x = 2 es el valor que se EXCLUYE porque hace que el denominador sea cero, y dividir entre cero no está definido.

2
Paso 2
Intersecciones con los ejes
▾

Con eje y (x = 0):

f(0) = (0 − 1)/(0 − 2) = (−1)/(−2) = 1/2
Eje yPunto (0 , 1/2)

Con eje x (f(x) = 0):

Una fracción es cero solo cuando el numerador es cero (y el denominador ≠ 0).

x² − 1 = 0 → (x−1)(x+1) = 0 → x = 1 o x = −1

Ambos valores están en el dominio (ninguno es x = 2). ✓

Eje xPuntos (−1 , 0) y (1 , 0)
¿Por qué?

f(x) = A/B = 0 únicamente si A = 0. No importa cuánto valga B (siempre que B ≠ 0). El denominador por sí solo no puede hacer que la fracción sea cero.

3
Paso 3
Simetría — ¿es par o impar?
▾
f(−x) = ((−x)² − 1) / (−x − 2) = (x² − 1) / (−x − 2)

¿Es esto igual a f(x) = (x²−1)/(x−2)? No, los denominadores difieren.

¿Es igual a −f(x) = −(x²−1)/(x−2)? Tampoco (los denominadores aún difieren).

SimetríaNinguna. No es par ni impar.

Nota: Que el numerador sea par (x²−1 solo tiene potencias pares) no alcanza. El denominador (x−2) rompe la simetría porque no es simétrico.

4
Paso 4
Asíntotas
▾

Asíntota Vertical (AV):

x = 2 (el denominador se anula y el numerador = 2²−1 = 3 ≠ 0)
⚠ Trampa

Si el numerador también fuera cero en x = 2, no habría asíntota vertical sino un agujero (discontinuidad evitable). Siempre verifica que el numerador sea distinto de cero donde el denominador se anula.

Asíntota Oblicua (AO):

El grado del numerador (2) = grado del denominador (1) + 1 → hay asíntota oblicua. Dividimos:

x² − 1 ÷ (x − 2)
Divisiónx² ÷ x = x
x·(x−2) = x²−2x
Resto: 2x−1
Segunda2x ÷ x = 2
2·(x−2) = 2x−4
Resto: 3
Resultadof(x) = x + 2 + 3/(x−2)

Cuando x → ±∞, el término 3/(x−2) → 0. La curva se acerca a la recta y = x + 2.

AsíntotasAV: x = 2 | AO: y = x + 2
¿Por qué no hay asíntota horizontal?

La regla: si grado(numerador) = grado(denominador) + 1, hay asíntota oblicua, no horizontal. La horizontal solo existe cuando el grado del numerador es ≤ grado del denominador.

5
Paso 5
Crecimiento y decrecimiento — f'(x)
▾

Usamos la regla del cociente: (u/v)' = (u'v − uv') / v²

u = x²−1, u' = 2x | v = x−2, v' = 1 f'(x) = [2x(x−2) − (x²−1)·1] / (x−2)² = [2x² − 4x − x² + 1] / (x−2)² = (x² − 4x + 1) / (x−2)²

Puntos críticos: f'(x) = 0 → numerador = 0 (el denominador (x−2)² > 0 siempre, salvo x=2 donde no está definida):

x² − 4x + 1 = 0 → x = (4 ± √12) / 2 = 2 ± √3 x₁ = 2 − √3 ≈ 0.27 x₂ = 2 + √3 ≈ 3.73

Tabla de signos de f':

Puntos clave en orden: x₁ = 2−√3, x = 2 (no pertenece al dom.), x₂ = 2+√3

IntervaloPunto pruebaNumerador x²−4x+1Denominador (x−2)²f'

¿Por qué (x−2)² siempre es positivo?

Cualquier número real al cuadrado es ≥ 0. Y en x = 2 no está definida la función, así que en todo el dominio (x−2)² > 0. El signo de f' lo determina únicamente el numerador.

6
Paso 6
Extremos locales
▾

Criterio de la primera derivada: analizamos el cambio de signo en los puntos críticos.

En x₁ = 2 − √3 ≈ 0.27: f' cambia de + a − → máximo local

f(2−√3) = ((2−√3)² − 1) / (2−√3 − 2) = (4 − 4√3 + 3 − 1) / (−√3) = (6 − 4√3) / (−√3) = (4√3 − 6) / √3 = 4 − 6/√3 = 4 − 2√3 ≈ 0.54

En x₂ = 2 + √3 ≈ 3.73: f' cambia de − a + → mínimo local

f(2+√3) = 4 + 2√3 ≈ 7.46
ExtremosMáx. local: (2−√3, 4−2√3) ≈ (0.27, 0.54) | Mín. local: (2+√3, 4+2√3) ≈ (3.73, 7.46)

Paradoja visual: El mínimo local (≈7.46) está más arriba que el máximo local (≈0.54). Esto es posible porque hay una asíntota vertical en x=2 que "separa" los dos extremos. Un extremo local es relativo a su entorno inmediato, no un mínimo global.

02
Función polinómica cúbica · Dificultad media
f(x) = x³ − 6x² + 9x − 2
Sin asíntotas · Múltiples extremos · Punto de inflexión real
1
Paso 1
Dominio
▾

Es un polinomio. Los polinomios están definidos para todo número real: no hay denominadores, raíces ni logaritmos.

DominioDom(f) = ℝ = (−∞, +∞)
2
Paso 2
Intersecciones con los ejes
▾

Eje y:

f(0) = 0 − 0 + 0 − 2 = −2 → Punto (0, −2)

Eje x: resolvemos x³ − 6x² + 9x − 2 = 0

Probamos x = 1 (Teorema del factor racional, raíces posibles ±1, ±2):

f(1) = 1 − 6 + 9 − 2 = 2 ≠ 0

Probamos x = 2:

f(2) = 8 − 24 + 18 − 2 = 0 ✓ → (x−2) es factor

Dividimos x³ − 6x² + 9x − 2 ÷ (x−2):

Cociente: x² − 4x + 1

Raíces del cociente: x = (4 ± √12)/2 = 2 ± √3

Eje xx = 2, x = 2−√3 ≈ 0.27, x = 2+√3 ≈ 3.73
Estrategia para cúbicas

Prueba siempre los divisores del término independiente como posibles raíces racionales. Una vez hallada una raíz, divide y reduce el grado del polinomio para encontrar las demás.

3
Paso 3
Simetría
▾
f(−x) = (−x)³ − 6(−x)² + 9(−x) − 2 = −x³ − 6x² − 9x − 2

¿Igual a f(x)? No. ¿Igual a −f(x) = −x³+6x²−9x+2? Tampoco.

SimetríaNinguna. No es par ni impar.

Nota: Las funciones cúbicas puras (x³) son impares. Pero en cuanto se añaden términos como −6x² o −2, la simetría se rompe porque esos términos tienen paridad distinta.

4
Paso 4
Asíntotas
▾

Los polinomios no tienen asíntotas. Cuando x → ±∞, f(x) → ±∞ (el término de mayor grado domina).

Término dominante: x³. Si x→+∞: f→+∞. Si x→−∞: f→−∞.
AsíntotasNinguna.
5
Paso 5
Crecimiento y decrecimiento — f'(x)
▾
f'(x) = 3x² − 12x + 9 = 3(x² − 4x + 3) = 3(x−1)(x−3)

Puntos críticos: x = 1 y x = 3

Intervalo(x−1)(x−3)f' = 3(x−1)(x−3)
x < 1−−+ → crece
1 < x < 3+−− → decrece
x > 3+++ → crece
¿Por qué la tabla de signos funciona así?

Cuando x < 1, ambos factores son negativos → su producto es positivo (negativo × negativo = positivo). Entre 1 y 3, el primer factor es positivo y el segundo negativo → producto negativo. Esta lógica de signos es la herramienta clave.

6
Paso 6
Extremos locales
▾

x = 1: f' cambia + → − → máximo local

f(1) = 1 − 6 + 9 − 2 = 2 → Máx. local en (1, 2)

x = 3: f' cambia − → + → mínimo local

f(3) = 27 − 54 + 27 − 2 = −2 → Mín. local en (3, −2)
ExtremosMáximo local (1, 2) | Mínimo local (3, −2)
⚠ Trampa

Aquí f(0) = −2 y f(3) = −2, el mismo valor. Algunos concluyen que (0,−2) también es mínimo. No: x = 0 no es punto crítico (f'(0) = 3(−1)(−3) = 9 ≠ 0), así que no es extremo. Solo son extremos los puntos donde f' = 0 o no existe, y además f' cambia de signo.

7

f''(x) = 6x − 12 = 6(x − 2)

f(2) = 8 − 24 + 18 − 2 = 0 → Punto de inflexión en (2, 0)
InflexiónPunto (2, 0) — la curva cambia de cóncava abajo a cóncava arriba

03
Función irracional · Dificultad media
f(x) = x · √(4 − x²)
Dominio acotado · Función par o impar · Extremos en dominio cerrado
1
Paso 1
Dominio
▾

La raíz cuadrada exige que el radicando sea ≥ 0:

4 − x² ≥ 0 → x² ≤ 4 → |x| ≤ 2 → −2 ≤ x ≤ 2
DominioDom(f) = [−2, 2]
⚠ Trampa: el radicando puede ser cero

El dominio incluye los extremos x = −2 y x = 2 porque √0 = 0 está perfectamente definido. El corchete [ ] significa que el extremo se incluye. Solo cuando hay logaritmo o denominador se excluye estrictamente.

2
Paso 2
Intersecciones con los ejes
▾

Eje y: f(0) = 0 · √4 = 0 → Punto (0, 0)

Eje x: f(x) = 0 cuando x = 0 o √(4−x²) = 0

√(4−x²) = 0 → 4−x² = 0 → x = ±2
Intersecciones eje x(−2, 0), (0, 0), (2, 0)
3
Paso 3
Simetría — ¡sorpresa!
▾
f(−x) = (−x) · √(4 − (−x)²) = (−x) · √(4 − x²) = −f(x)
SimetríaFunción IMPAR. Simétrica respecto al origen.
¿Por qué esto ayuda?

Al ser impar, basta estudiar f en [0, 2] y luego reflejar respecto al origen para obtener el comportamiento en [−2, 0]. Reduce el trabajo a la mitad.

⚠ Trampa: verificar el dominio antes de clasificar paridad

Para que f sea par o impar, el dominio debe ser simétrico respecto al origen (si x está en el dominio, −x también debe estarlo). Aquí Dom = [−2,2] sí es simétrico. Si el dominio no fuera simétrico, f no podría ser ni par ni impar.

4
Paso 4
Asíntotas
▾

El dominio es el intervalo acotado [−2, 2]. No hay x que tienda a ±∞ dentro del dominio, y no hay denominadores que se anulen.

AsíntotasNinguna.
5
Paso 5
Crecimiento y decrecimiento — f'(x)
▾

Aplicamos la regla del producto: (uv)' = u'v + uv'

u = x, u' = 1 | v = √(4−x²) = (4−x²)^(1/2), v' = (1/2)(4−x²)^(−1/2)·(−2x) = −x/√(4−x²) f'(x) = 1·√(4−x²) + x·(−x/√(4−x²)) = √(4−x²) − x²/√(4−x²) = [(4−x²) − x²] / √(4−x²) = (4 − 2x²) / √(4−x²)

f'(x) = 0 cuando el numerador = 0 (el denominador > 0 en el interior del dominio):

4 − 2x² = 0 → x² = 2 → x = ±√2
⚠ Trampa: f' no existe en los extremos del dominio

En x = ±2 el denominador √(4−x²) = 0, así que f' no está definida ahí. No confundas "f' no existe" con "hay asíntota". En extremos del dominio, simplemente la derivada lateral no existe o es infinita. Los extremos x = ±2 son puntos del dominio de f pero no de f'.

Como f es impar, estudiamos solo x ∈ [0, 2]:

Intervalo4−2x²√(4−x²)f'
(0, √2)positivopositivo+ → crece
(√2, 2)negativopositivo− → decrece

Por simetría impar: en (−2, −√2) crece, en (−√2, 0) decrece.

6
Paso 6
Extremos locales y globales
▾

x = √2: f' cambia + → − → máximo local

f(√2) = √2 · √(4−2) = √2 · √2 = 2 → Máx. local en (√2, 2)

x = −√2: por simetría impar → f(−√2) = −f(√2) = −2 → mínimo local

Extremos localesMáximo: (√2, 2) | Mínimo: (−√2, −2)

Extremos globales: Como el dominio es un intervalo cerrado [−2, 2], por el Teorema del Valor Extremo f alcanza un máximo y un mínimo absolutos. El máximo absoluto es 2 en x = √2, y el mínimo absoluto es −2 en x = −√2 (los extremos del dominio dan f(±2) = 0).

Paso 7

▾

u = 4−2x², u' = −4x | v = √(4−x²), v' = −x/√(4−x²) f''(x) = [−4x·√(4−x²) − (4−2x²)·(−x/√(4−x²))] / (4−x²) = [−4x(4−x²) + x(4−2x²)] / (4−x²)^(3/2) = x[−16+4x²+4−2x²] / (4−x²)^(3/2) = x(2x²−12) / (4−x²)^(3/2) = 2x(x²−6) / (4−x²)^(3/2)

04
Función racional · Dificultad alta
f(x) = (x³) / (x² − 1)
Dos asíntotas verticales · Asíntota oblicua · Función impar
1
Paso 1
Dominio
▾
x² − 1 ≠ 0 → (x−1)(x+1) ≠ 0 → x ≠ 1 y x ≠ −1
Dominioℝ \ {−1, 1} = (−∞,−1) ∪ (−1,1) ∪ (1,+∞)
2
Paso 2
Intersecciones con los ejes
▾

Eje y: f(0) = 0/(0−1) = 0 → Punto (0, 0)

Eje x: x³ = 0 → x = 0 (único cero, con multiplicidad 3)

InterseccionesSolo el origen (0, 0) — es a la vez intersección con eje x y con eje y
3
Paso 3
Simetría
▾
f(−x) = (−x)³ / ((−x)²−1) = −x³ / (x²−1) = −f(x)
SimetríaFunción IMPAR. Simétrica respecto al origen.
Cómo reconocer funciones impares rápido

En cocientes racionales: si el numerador tiene solo potencias impares de x y el denominador solo potencias pares (o viceversa con signo consistente), la función es impar. Aquí: numerador x³ (impar) y denominador x²−1 (par). Esto garantiza f(−x) = −f(x).

4
Paso 4
Asíntotas — verticales, oblicua
▾

Asíntotas Verticales:

En x = 1: numerador = 1³ = 1 ≠ 0 → AV: x = 1 En x = −1: numerador = (−1)³ = −1 ≠ 0 → AV: x = −1

Asíntota Oblicua: grado(num) = 3, grado(den) = 2. Como 3 = 2 + 1 → hay AO.

x³ ÷ (x²−1):
Paso 1x³ ÷ x² = x
x·(x²−1) = x³ − x
Resto: x
Resultadof(x) = x + x/(x²−1)

Cuando x→±∞, x/(x²−1)→0
AsíntotasAV: x = 1 y x = −1 | AO: y = x

Comprobación con la simetría: La AO es y = x, que también es impar (pasa por el origen y f(−x)=−f(x)). Coherente con que la función sea impar.

5
Paso 5
Crecimiento y decrecimiento — f'(x)
▾

Regla del cociente:

f'(x) = [3x²(x²−1) − x³·2x] / (x²−1)² = [3x⁴ − 3x² − 2x⁴] / (x²−1)² = (x⁴ − 3x²) / (x²−1)² = x²(x² − 3) / (x²−1)²

f'(x) = 0 cuando: x² = 0 → x = 0, o x²−3 = 0 → x = ±√3

⚠ Trampa: x = 0 es un punto crítico especial

f'(0) = 0, pero ¿cambia de signo? Analicemos: el factor x² es siempre ≥ 0. Y (x²−1)² también es siempre ≥ 0. Entonces el signo de f' depende solo del signo de x²−3. En x = 0: x²−3 = −3 < 0. A ambos lados de 0 el signo de x²−3 sigue siendo negativo (para x cercano a 0). f' no cambia de signo en x = 0 → no es extremo, sino punto de inflexión con tangente horizontal.

Intervalox²x²−3(x²−1)²f'
(−∞,−√3)++++ → crece
(−√3,−1)+−+− → decrece
(−1,0)+−+− → decrece
(0,1)+−+− → decrece
(1,√3)+−+− → decrece
(√3,+∞)++++ → crece
6
Paso 6
Extremos locales
▾

x = −√3: f' cambia +→− → máximo local

f(−√3) = (−√3)³ / ((−√3)²−1) = −3√3 / (3−1) = −3√3/2 ≈ −2.60

x = 0: f' no cambia de signo (sigue negativa a ambos lados) → no es extremo

x = √3: f' cambia −→+ → mínimo local

f(√3) = (√3)³ / ((√3)²−1) = 3√3/2 ≈ 2.60
ExtremosMáx. local: (−√3, −3√3/2) | Mín. local: (√3, 3√3/2)
⚠ Trampa: el máximo local está por debajo del mínimo local

Sí, f(−√3) ≈ −2.60 (máximo local) y f(√3) ≈ 2.60 (mínimo local). Esto parece contradictorio pero tiene sentido: están en partes desconectadas del dominio (separadas por las asíntotas verticales). Los extremos locales son relativos a su rama, no al total de la función.

7
Paso 7
Concavidad e inflexión — f''(x)
▾

f'(x) = x²(x²−3)/(x²−1)². Derivamos (es largo; expandimos primero):

Usando que f(x) = x + x/(x²−1), es más fácil derivar esto:

f'(x) = 1 + (x²−1−2x²)/(x²−1)² = 1 + (−x²−1)/(x²−1)² = 1 − (x²+1)/(x²−1)² f''(x) = − [(2x(x²−1)² − (x²+1)·2(x²−1)·2x] / (x²−1)⁴ = −2x[(x²−1) − 2(x²+1)] / (x²−1)³ = −2x[x²−1−2x²−2] / (x²−1)³ = −2x(−x²−3) / (x²−1)³ = 2x(x²+3) / (x²−1)³

Nota: x²+3 > 0 siempre. El signo de f'' depende de x y (x²−1)³:
