Cómo despejar x — recordatorio rápido

  • 01Identifica dónde está la x y qué operaciones la rodean.
  • 02Aplica la operación inversa en ambos lados: si suma, resta; si multiplica, divide.
  • 03Si la x está dentro de un denominador, multiplica por ese denominador en ambos lados primero.
  • 04Si la x aparece en varios términos, agrúpalos en un lado y saca factor común.
  • 05Comprueba siempre tu resultado sustituyendo x en la ecuación original.

y = |x − 3|
Despeja x. El valor absoluto da dos casos.
Tu respuesta
El valor absoluto significa: x − 3 puede ser positivo o negativo.

Caso 1: x − 3 ≥ 0 → y = x − 3 → x = y + 3
Caso 2: x − 3 < 0 → y = −(x − 3) = −x + 3 → x = 3 − y

⚠️ Restricción: como y = |x−3|, siempre y ≥ 0
⚠️ Clave: con valor absoluto siempre hay dos soluciones posibles.
x = y + 3  ó  x = 3 − y   (con y ≥ 0)
