01
Fundamentos

¿Qué es una función?

Una función f de un conjunto A en un conjunto B es una regla que asigna a cada elemento x ∈ A exactamente un único elemento y ∈ B. Se escribe y = f(x), donde x es la variable independiente e y es la variable dependiente.

Piénsalo así: una función es como una máquina. Le metes un número (input = x), le aplica una regla, y te da un resultado (output = y). La condición esencial es que por cada entrada, solo puede haber una salida.

Notación y terminología esencial

Notación estándar

f : A → B se lee "f va de A en B"

f(x) = expresión define la regla

f(a) es el valor de f cuando x = a

Vocabulario clave

Dominio (Dom f): conjunto de todos los x válidos

Codominio: conjunto B (donde pueden caer los valores)

Rango / Imagen: valores que f realmente toma

Sea f(x) = x² + 1. Calcula f(3), f(−2) y f(0).

f(3) = (3)² + 1 = 9 + 1 = 10

f(−2) = (−2)² + 1 = 4 + 1 = 5

f(0) = (0)² + 1 = 0 + 1 = 1

Nota que f(3) ≠ f(−3) no es necesario, pero f siempre da UN solo valor por cada x.

¿Cuándo NO es función? — Prueba de la recta vertical

Prueba de la Recta Vertical: Una curva en el plano cartesiano es la gráfica de una función si y solo si ninguna recta vertical la corta en más de un punto.

Si una recta vertical x = a corta la gráfica en dos puntos (a, y₁) y (a, y₂) con y₁ ≠ y₂, entonces a ese valor de x le corresponden dos salidas distintas → NO es función.

¿Es función x² + y² = 9? (círculo de radio 3)

Para x = 0: y² = 9 → y = 3 o y = −3. Dos valores para un mismo x. ❌ NO es función.

¿Es función y = √(9 − x²)? (semicírculo superior) → solo da valores positivos → ✅ SÍ es función.

Relación vs Función

Relación (caso general)

Cualquier conjunto de pares ordenados (x, y). Un x puede tener varios y. Ejemplo: {(1,2), (1,5), (3,4)} — el 1 aparece dos veces con distintos y. No es función.

Función (caso especial)

Relación donde cada x tiene exactamente un y. Ejemplo: {(1,2), (2,5), (3,4)} — cada x aparece una sola vez. SÍ es función.

Conjuntos clave

Dominio, Rango y Codominio

Dominio Natural (o Dominio Implícito)

Es el conjunto más grande de valores reales para los que f(x) está definida. Para encontrarlo, hay que identificar qué valores de x causan problemas.

Restricciones del dominio:

1. Denominadores: el denominador ≠ 0
2. Raíces pares: el radicando ≥ 0 (raíces cuadradas, de cuarto, etc.)
3. Logaritmos: el argumento > 0
4. Combinaciones: aplica todas las restricciones simultáneamente

Método paso a paso para hallar el dominio

1
Identifica qué operaciones "problemáticas" hay en la función (divisiones, raíces, logaritmos).
2
Escribe las restricciones correspondientes como desigualdades o inequaciones.
3
Resuelve cada restricción para obtener los valores de x excluidos.
4
Expresa el dominio en notación de intervalo o de conjunto.

Ejemplo 1: f(x) = 1 / (x − 3)

Restricción: x − 3 ≠ 0 → x ≠ 3

Dom(f) = ℝ \ {3} = (−∞, 3) ∪ (3, +∞)

Ejemplo 2: f(x) = √(x − 2)

Restricción: x − 2 ≥ 0 → x ≥ 2

Dom(f) = [2, +∞)

Ejemplo 3: f(x) = √(x + 1) / (x − 4)

Restricción 1 (raíz): x + 1 ≥ 0 → x ≥ −1
Restricción 2 (denominador): x − 4 ≠ 0 → x ≠ 4

Dom(f) = [−1, 4) ∪ (4, +∞)

Ejemplo 4: f(x) = ln(x² − 4)

Restricción: x² − 4 > 0 → (x−2)(x+2) > 0 → x < −2 o x > 2

Dom(f) = (−∞, −2) ∪ (2, +∞)

Rango o Imagen de una Función

El rango (o imagen) es el conjunto de todos los valores que efectivamente toma f(x). Es distinto del codominio, que es el conjunto donde "podrían" caer los valores.

Rango de funciones comunes

f(x) = x² → Rango = [0, +∞)

f(x) = x³ → Rango = (−∞, +∞)

f(x) = √x → Rango = [0, +∞)

f(x) = |x| → Rango = [0, +∞)

Estrategia para hallar el rango

1. Despeja x en función de y
2. Aplica las restricciones a y
3. Verifica con la gráfica
4. Usa análisis (máx/mín) si es posible

Halla el rango de f(x) = x² − 4x + 5

Completa el cuadrado: f(x) = (x−2)² + 1

Como (x−2)² ≥ 0 siempre, entonces f(x) ≥ 1 siempre.

El mínimo es 1 (cuando x = 2). Rango = [1, +∞)

Función Constante: f(x) = c

Dominio: ℝ · Rango: {c} · Gráfica: recta horizontal · Pendiente = 0

Función Lineal: f(x) = mx + b

m = pendiente (inclinación), b = intercepto en y. Gráfica: recta. Dom y Rango = ℝ.

m = (y₂ − y₁) / (x₂ − x₁) = Δy / Δx

La pendiente indica cuánto sube (o baja) y por cada unidad que avanza x.

Función Cuadrática: f(x) = ax² + bx + c

Gráfica: parábola. Si a > 0 abre hacia arriba (mínimo); si a < 0 abre hacia abajo (máximo).

Vértice: x_v = −b/(2a) , y_v = f(x_v)
Discriminante: Δ = b² − 4ac
Discriminante ΔRaíces realesIntersecciones con eje x
Δ > 0Dos raíces reales distintasDos puntos
Δ = 0Una raíz real dobleUn punto (toca el eje)
Δ < 0No hay raíces realesNo corta el eje x

Analizar f(x) = x² − 4x + 3

a = 1 > 0 → parábola abre arriba. Vértice: x_v = 4/2 = 2, y_v = 4 − 8 + 3 = −1. Vértice: (2, −1)

Δ = 16 − 12 = 4 > 0. Raíces: x = (4 ± 2)/2 → x = 1 y x = 3.

Rango = [−1, +∞)

B · Por su comportamiento

Función Par

f es par si f(−x) = f(x) para todo x en su dominio. Gráfica: simétrica respecto al eje Y.

Ejemplos: f(x) = x², f(x) = |x|, f(x) = cos(x), f(x) = x⁴ − 3x² + 1

Función Impar

f es impar si f(−x) = −f(x) para todo x en su dominio. Gráfica: simétrica respecto al origen.

Ejemplos: f(x) = x³, f(x) = x, f(x) = sen(x), f(x) = x⁵ − x

Determinar si f(x) = x³ − 4x es par, impar o ninguna.

f(−x) = (−x)³ − 4(−x) = −x³ + 4x = −(x³ − 4x) = −f(x)

Como f(−x) = −f(x) → función IMPAR

Función Monótona

Creciente en (a, b)

Si x₁ < x₂ → f(x₁) < f(x₂). A medida que x aumenta, y también aumenta.

Decreciente en (a, b)

Si x₁ < x₂ → f(x₁) > f(x₂). A medida que x aumenta, y disminuye.

Nota: Con Cálculo I podemos determinar los intervalos de crecimiento y decrecimiento usando la derivada: f'(x) > 0 → creciente; f'(x) < 0 → decreciente.

C · Función Definida por Partes (o a Trozos)

Una función que tiene diferentes fórmulas en diferentes partes de su dominio.

Ejemplo: Valor absoluto definido por partes

|x| = { x, si x ≥ 0
       { −x, si x < 0

Para evaluar: si x = 3 → usas la primera parte: |3| = 3
Si x = −5 → usas la segunda parte: |−5| = −(−5) = 5

Sea: f(x) = { x² si x < 0 | 2x + 1 si x ≥ 0

f(−3) = (−3)² = 9 (usa primera parte, ya que −3 < 0)

f(2) = 2(2)+1 = 5 (usa segunda parte, ya que 2 ≥ 0)

f(0) = 2(0)+1 = 1 (usa segunda parte, ya que 0 ≥ 0)

Operaciones con Funciones

Operaciones Básicas

Dadas f y g con dominios Df y Dg:

OperaciónFórmulaDominio
(f + g)(x)f(x) + g(x)Df ∩ Dg
(f − g)(x)f(x) − g(x)Df ∩ Dg
(f · g)(x)f(x) · g(x)Df ∩ Dg
(f / g)(x)f(x) / g(x)Df ∩ Dg, con g(x) ≠ 0

Sea f(x) = x + 2, Dom f = ℝ; y g(x) = √x, Dom g = [0,+∞)

(f+g)(x) = x + 2 + √x → Dom = [0,+∞)

(f/g)(x) = (x+2)/√x → Dom = (0,+∞) [excluye x=0 pues g(0)=0]

Composición de Funciones

La composición de f y g se denota (f ∘ g)(x) = f(g(x)). Primero se aplica g, luego f. El dominio de f∘g es {x ∈ Dom(g) : g(x) ∈ Dom(f)}.

¡Ojo! En general f ∘ g ≠ g ∘ f. La composición no es conmutativa.
1
Evalúa la función interior g(x).
2
Sustituye ese resultado como argumento de la función exterior f.
3
Simplifica la expresión resultante.
4
Determina el dominio aplicando las restricciones de ambas funciones.

f(x) = x² + 1, g(x) = 2x − 3

(f ∘ g)(x) = f(g(x)) = f(2x−3) = (2x−3)² + 1 = 4x² − 12x + 9 + 1 = 4x² − 12x + 10

(g ∘ f)(x) = g(f(x)) = g(x²+1) = 2(x²+1) − 3 = 2x² − 1

Claramente son distintas. ✓

Descomposición: Si h(x) = √(x² + 5), exprésala como composición.

Solución: g(x) = x² + 5 (función interior), f(x) = √x (función exterior)

h(x) = (f ∘ g)(x) = f(g(x)) = √(x²+5) ✓

(Útil para la regla de la cadena en derivadas)

Función Inversa

Si f es biyectiva, su inversa f⁻¹ es la función tal que: f⁻¹(f(x)) = x y f(f⁻¹(y)) = y. La gráfica de f⁻¹ es el reflejo de la gráfica de f respecto a la recta y = x.

Cómo hallar f⁻¹ algebraicamente

1
Escribe y = f(x).
2
Despeja x en términos de y.
3
Intercambia x e y (renombra x como y).
4
La expresión resultante es f⁻¹(x). Determina su dominio.

Halla f⁻¹ de f(x) = 3x − 6

1) y = 3x − 6

2) y + 6 = 3x → x = (y+6)/3

3) Intercambio: y = (x+6)/3

4) f⁻¹(x) = (x+6)/3 = x/3 + 2

Verificación: f(f⁻¹(x)) = 3(x/3+2) − 6 = x + 6 − 6 = x ✓

Halla f⁻¹ de f(x) = (x+1)/(x−2), x ≠ 2

y = (x+1)/(x−2)
y(x−2) = x+1
xy − 2y = x + 1
xy − x = 2y + 1
x(y−1) = 2y+1
x = (2y+1)/(y−1)

f⁻¹(x) = (2x+1)/(x−1), Dom = ℝ \ {1}

Análisis completo

Estudio Completo de una Función

Este es el análisis sistemático que se hace en Cálculo I para entender completamente el comportamiento de una función. Sigue este orden siempre:

Pasos del estudio completo:

1. Dominio · 2. Intersecciones con ejes · 3. Simetría · 4. Asíntotas · 5. Crecimiento / Decrecimiento · 6. Extremos · 7. Concavidad e Inflexión · 8. Rango · 9. Gráfica

1 · Dominio

Ya visto. Hallar todos los x para los que f está definida.

2 · Intersecciones con los ejes

Con el eje x (raíces/ceros)

Resolver f(x) = 0. Los puntos son (x₀, 0) donde la curva toca o cruza el eje horizontal.

Con el eje y (intercepto)

Evaluar f(0), si 0 está en el dominio. El punto es (0, f(0)).

3 · Simetría

Verificar si es par (f(−x) = f(x)) o impar (f(−x) = −f(x)). Si no es ninguna, no hay simetría especial.

4 · Asíntotas

Asíntota Vertical (AV)

La recta x = a es asíntota vertical si límx→a f(x) = ±∞. Ocurre típicamente donde el denominador se anula y el numerador no.

Asíntota Horizontal (AH)

La recta y = L es asíntota horizontal si límx→+∞ f(x) = L o límx→−∞ f(x) = L.

Para funciones racionales f(x) = p(x)/q(x), con grado n de p y grado m de q:

Comparación de gradosAsíntota horizontal
n < my = 0
n = my = coef. líder de p / coef. líder de q
n > mNo hay AH (hay asíntota oblicua)

Asíntota Oblicua (AO)

Cuando el grado del numerador es exactamente 1 más que el del denominador. Se halla dividiendo: f(x) = (cociente lineal) + (resto/q(x)). La asíntota es y = cociente lineal.

5 · Crecimiento y Decrecimiento (usando f')

Criterio de la primera derivada:
· Si f'(x) > 0 en (a,b) → f es creciente en (a,b)
· Si f'(x) < 0 en (a,b) → f es decreciente en (a,b)
· Si f'(x) = 0 en x = c → c es un punto crítico

Procedimiento

1
Calcula f'(x).
2
Halla los puntos críticos: f'(x) = 0 y donde f'(x) no existe.
3
Haz una tabla de signos: divide la recta real con los puntos críticos y analiza el signo de f' en cada intervalo.
4
Concluye dónde crece y dónde decrece.

6 · Extremos Locales

Criterio de la primera derivada para extremos:
En un punto crítico x = c:
· Si f' cambia de + a − → máximo local en (c, f(c))
· Si f' cambia de − a + → mínimo local en (c, f(c))
· Si f' no cambia de signo → no es extremo (punto de inflexión con tangente horizontal)

Criterio de la segunda derivada (alternativo):
En un punto crítico c donde f'(c) = 0:
· Si f''(c) > 0 → mínimo local
· Si f''(c) < 0 → máximo local
· Si f''(c) = 0 → el criterio no decide (vuelve al criterio de la 1ª derivada)

7 · Concavidad y Puntos de Inflexión

Criterio de la segunda derivada para concavidad:
· Si f''(x) > 0 en (a,b) → f es cóncava hacia arriba (forma de ∪) en (a,b)
· Si f''(x) < 0 en (a,b) → f es cóncava hacia abajo (forma de ∩) en (a,b)

Un punto de inflexión es un punto donde la concavidad cambia. Para hallarlo: f''(x) = 0 o f''(x) no existe, y verificar que la concavidad efectivamente cambia.

Ejemplo completo: f(x) = x³ − 3x² − 9x + 5

1. Dominio: ℝ (polinomio, siempre definida)

2. Intersección eje y: f(0) = 5 → punto (0, 5)

3. Simetría: f(−x) ≠ f(x) y ≠ −f(x) → ninguna simetría especial

4. Asíntotas: ninguna (es polinomio)

5. f'(x) = 3x² − 6x − 9 = 3(x² − 2x − 3) = 3(x−3)(x+1)

Puntos críticos: x = −1 y x = 3

Tabla de signos de f':
· x < −1: prueba x = −2: 3(−5)(−3) = + → creciente
· −1 < x < 3: prueba x = 0: 3(−3)(1) = − → decreciente
· x > 3: prueba x = 4: 3(1)(5) = + → creciente

6. Extremos:
x = −1: f' cambia de + a − → máximo local. f(−1) = −1−3+9+5 = 10 → Máx. local en (−1, 10)
x = 3: f' cambia de − a + → mínimo local. f(3) = 27−27−27+5 = −22 → Mín. local en (3, −22)

7. f''(x) = 6x − 6 = 6(x−1)

f''(x) = 0 → x = 1 (posible inflexión)
· x < 1: f'' < 0 → cóncava abajo (∩)
· x > 1: f'' > 0 → cóncava arriba (∪)
Cambia → x = 1 es punto de inflexión. f(1) = 1−3−9+5 = −6 → Inflexión en (1, −6)

Límites — La herramienta fundamental

El límite de f(x) cuando x → a es L si los valores de f(x) se acercan tanto como queramos a L a medida que x se acerca a a (sin necesariamente llegar a a). Se escribe: límx→a f(x) = L

Tipo de límiteQué significa
límx→a f(x) = LLímite bilateral: se acerca por ambos lados
límx→a⁺ f(x) = LLímite lateral derecho: x se acerca desde la derecha
límx→a⁻ f(x) = LLímite lateral izquierdo: x se acerca desde la izquierda
límx→+∞ f(x) = LComportamiento cuando x crece sin límite
límx→a f(x) = ±∞Asíntota vertical en x = a

El límite bilateral existe si y solo si los dos límites laterales existen y son iguales:
límx→a f(x) = L ⟺ límx→a⁻ f(x) = L = límx→a⁺ f(x)

Continuidad

f es continua en x = a si se cumplen las tres condiciones:

1. f(a) está definida
2. límx→a f(x) existe
3. límx→a f(x) = f(a)

Intuitivamente: puedes trazar la gráfica sin levantar el lápiz del papel en x = a.

Tipos de discontinuidad

De saltoLos límites laterales existen pero son distintosFunción escalón, valor absoluto partido

Funciones Trascendentes

Funciones Exponenciales: f(x) = aˣ

f(x) = aˣ donde a > 0 y a ≠ 1. La base más importante es e ≈ 2.71828... (el número de Euler). f(x) = eˣ se llama la exponencial natural.

Si a > 1 (crecimiento)

Función estrictamente creciente. Cruza el eje y en (0,1). Asíntota horizontal: y = 0. Dom = ℝ, Rango = (0, +∞)

Si 0 < a < 1 (decaimiento)

Función estrictamente decreciente. Cruza el eje y en (0,1). Asíntota horizontal: y = 0. Dom = ℝ, Rango = (0, +∞)

Funciones Logarítmicas: f(x) = log_a(x)

El logaritmo es la inversa de la exponencial. log_a(x) = y significa que aʸ = x. El más importante es el logaritmo natural ln(x) = log_e(x).

Dominio: (0, +∞) · Rango: ℝ · Pasa por (1, 0) siempre · Asíntota vertical: x = 0

Propiedades de los Logaritmos (fundamentales)

ln(xy) = ln x + ln y
ln(x/y) = ln x − ln y
ln(xⁿ) = n · ln x
ln(eˣ) = x y e^(ln x) = x (son inversas)
Cambio de base: log_a(x) = ln(x) / ln(a)

Simplifica: ln(e³) + ln(1/e) − 2·ln(e²)

= 3 + (−1) − 2(2) = 3 − 1 − 4 = −2

Checklist de Estudio Completo

1
Dominio: ¿Dónde está definida f? (denominadores ≠ 0, radicandos ≥ 0, logaritmos > 0)
2
Intersecciones: Con eje x → f(x)=0; con eje y → f(0)
3
Simetría: ¿Es par, impar o ninguna?
4
Asíntotas: Verticales (denominador=0), horizontales (límite en ±∞), oblicuas (div. polinómica)
5
Derivada f': Puntos críticos, intervalos de crecimiento/decrecimiento, extremos locales
6
Segunda derivada f'': Concavidad, puntos de inflexión
7
Rango: Determinar el conjunto de valores que toma f
8
Gráfica: Con toda la información anterior, trazar la curva con precisión
Para el CSCA: Practica el estudio completo con funciones racionales, irracionales y trascendentes. Los examinadores suelen combinar varios tipos. Siempre justifica cada paso con el criterio correspondiente. Dominar las identidades trigonométricas y las propiedades de logaritmos es esencial.
